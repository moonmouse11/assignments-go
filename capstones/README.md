# Капстоуны — интеграционные задачи

Капстоун соединяет несколько глав в один рабочий инструмент. Пререквизит —
пройти указанные главы: капстоун **импортирует их пакеты как библиотеки**
(`import "assignments-go/16-password"`), так что без глав он не соберётся
в уме, а с ними — собирается в работающий инструмент.

Паттерн тот же, что у глав: заготовка с `TODO`, тесты, эталонный
`solution.go` за build-тегом. Изюминка: в режиме `-tags solution` капстоун
получает **эталоны** всех глав — интеграция проверяется целиком.

| # | Капстоун | Собирает главы | Что получается |
|---|----------|----------------|----------------|
| 1 | [01-password-manager](01-password-manager/README.md) | [`10-pwdgen`](../10-pwdgen/README.md), [`16-password`](../16-password/README.md) | менеджер паролей: генерация + хранилище + защищённый файл |
| 2 | [02-minici](02-minici/README.md) | [`28-srctrace`](../28-srctrace/README.md), [`30-buildsystem`](../30-buildsystem/README.md) | мини-CI: реестр сборок + трассировка, встраиваемая в приложение |

## Проверка

```
go test ./capstones/...                  # красные (TODO)
go test -tags solution ./capstones/...   # зелёные (эталоны всех глав)
```

## Как добавлять свои

Возьми две-три главы, чьи API стыкуются, и спроектируй клей поверх них:
новая функциональность — только интеграция, всё остальное — из глав.
